 # MahreenKiran Data Analytics Portfolio

Business data analytics portfolio featuring SQL, Power BI, Excel, KPI reporting, customer analysis, sales performance and operational insights.

## About This Portfolio

This portfolio demonstrates my ability to analyse business data, validate data quality, define meaningful KPIs and translate analytical results into clear business insights.

The projects focus on practical business questions rather than isolated technical exercises. Each project is designed to show the complete analytical process, including:

- understanding the business problem
- reviewing the data structure and table grain
- performing data-quality checks
- writing reliable SQL queries
- analysing sales, customer, product and operational performance
- building Power BI dashboards
- presenting evidence-based findings and recommendations

## Portfolio Projects

### 1. AdventureWorks Sales and Customer Performance Analysis

**Tools:** SQL Server, Power BI, Excel, GitHub

This end-to-end business data analysis project uses the [Microsoft AdventureWorks2025 sample database](https://github.com/microsoft/sql-server-samples/tree/master/samples/databases/adventure-works) to evaluate company sales, customer behaviour, product demand, regional performance and operational efficiency.

The analysis includes:

- total revenue, total orders, total units sold and average order value
- month-over-month sales performance
- top products by revenue
- category and subcategory performance
- category revenue contribution
- top customers by revenue
- customer order frequency
- customer value segmentation
- country and territory performance
- salesperson performance
- low-performing and unsold products
- order fulfilment performance
- inactive customer analysis
- order value segmentation
- data-quality validation

[View the AdventureWorks project](./AdventureWorks_Sales_Analysis/)

**Note:** This project was created for portfolio and learning purposes. It should not be interpreted as analysis completed for a real employer.

## Data Quality Approach

Before calculating KPIs, the projects check for:

- duplicate identifiers
- invalid quantities
- negative sales values
- invalid discounts
- missing important fields
- unmatched order records
- unmatched products
- invalid date sequences
- dataset coverage and record counts

This helps ensure that the final analysis is based on reliable data.

## Business Analysis Approach

Each major result is interpreted using the following structure:

**Finding:** What the data shows.

**Business meaning:** Why the result matters.

**Recommendation:** What action the business could consider.

**Evidence:** The supporting KPI, SQL query or dashboard visual.
