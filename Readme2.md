## 2. Patient Conditions, Treatment and Healthcare Utilisation Analysis

**Tools:** SQL Server • T-SQL • Power BI • DAX • Power Query • Excel

An end-to-end healthcare analytics project using synthetic Synthea data to explore patient demographics, healthcare utilisation, clinical activity and healthcare costs.

### Analysis Areas

- patient demographics
- healthcare visit utilisation
- high-utilisation patient groups
- conditions and clinical findings
- medication activity
- procedure activity
- healthcare cost analysis
- payer coverage
- cost segmentation
- longitudinal data-quality validation
- interactive Power BI reporting

### Key Analytical Themes

The analysis showed how healthcare utilisation and condition burden varied across patient groups, how a small number of patients accounted for disproportionately high healthcare activity, and how visit frequency and cost intensity contributed differently to overall expenditure.

The project also demonstrates careful interpretation of synthetic clinical data and transparent documentation of logical data-quality issues.

## 3. E-Commerce Marketing, Conversion and Customer Journey Analysis

**Tools:** SQL Server • T-SQL • Power BI • DAX • Power Query • GitHub

An end-to-end e-commerce analytics project using the Maven Analytics Fuzzy Factory dataset to examine marketing acquisition, website behaviour, conversion, orders, revenue, profitability, products and refunds.

### Dataset Scale

- **472,871** website sessions
- **1,188,124** pageviews
- **32,313** completed orders
- **40,025** order items
- **1,731** refund records

### Analysis Areas

- monthly website and order performance
- marketing channel effectiveness
- campaign performance
- desktop vs mobile conversion
- landing-page performance
- session engagement
- repeat-user behaviour
- customer journey funnel
- order value segmentation
- multi-item order performance
- product revenue ranking
- refund analysis
- month-on-month revenue growth
- rolling performance
- Power BI dashboard reporting

### Selected Findings

- Desktop conversion reached approximately **8.50%**, compared with **3.09% on mobile**.
- Paid Search generated approximately **$1.48M in net revenue**.
- The largest major funnel drop occurred between **Product Views and Cart**.
- Repeat users converted more successfully than non-repeat users.
- Multi-item orders generated substantially higher average revenue and gross profit.
- The Original Mr. Fuzzy contributed approximately **62.5% of total item revenue**.

# Analytical Approach

Each project follows a consistent end-to-end workflow:

**business question → data structure → validation → transformation → SQL analysis → KPI development → Power BI reporting → findings → recommendations**

### 1. Understand the Business Question

The analysis begins by defining what the stakeholder or business needs to understand.

### 2. Review Data Structure

Tables, grain, primary keys and relationships are reviewed before calculations are created.

### 3. Validate Data Quality

Checks are performed for issues such as:

- duplicate identifiers
- NULL primary keys
- broken relationships
- missing analytical fields
- invalid financial values
- inconsistent dates
- reconciliation issues
- logical anomalies

### 4. Engineer Analytical Fields

Derived variables are created where required to support segmentation, customer behaviour, profitability, time analysis and reporting.

### 5. Analyse Business Performance

SQL is used to investigate patterns across customers, products, sales, marketing, healthcare activity and operations.

### 6. Build Power BI Reporting

Key findings are translated into interactive dashboards designed for business-facing interpretation.

### 7. Translate Results into Action

Each project concludes with clear findings and recommendations supported by analytical evidence.

---

# Data Quality Approach

Data-quality validation is treated as part of the analysis rather than a separate technical exercise.

Across the portfolio, checks include:

- primary-key uniqueness
- NULL key checks
- referential integrity
- missing important fields
- duplicate business records
- invalid financial values
- timeline consistency
- order and item reconciliation
- refund consistency
- healthcare timeline validation
- dataset coverage and row counts

The objective is to ensure that business conclusions are supported by reliable and well-understood data.

---

# Business Analysis Approach

Analytical results are interpreted using four questions:

**Finding:** What does the data show?

**Business meaning:** Why does the result matter?

**Recommendation:** What action could be considered?

**Evidence:** Which KPI, SQL result or dashboard visual supports the conclusion?

This approach helps move the analysis beyond reporting metrics towards practical decision support.
